# Contributing to Benson Increments Calculator

Thank you for your interest in contributing to the Benson Increments Calculator! We welcome contributions from the community.

## How to Contribute

### Reporting Issues

- Use the [issue tracker](https://github.com/PrashantKumarChem/Benson-Increments-Calculator/issues) to report bugs or request features.
- Provide a clear description, steps to reproduce, and expected vs. actual behavior.
- Include your environment details (Python version, OS, etc.).

### Contributing Code

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes.
4. Ensure tests pass and code is linted.
5. Commit your changes: `git commit -m 'Add some feature'`
6. Push to the branch: `git push origin feature/your-feature-name`
7. Open a pull request.

### Code Style

- Follow PEP 8 for Python code.
- Use meaningful variable and function names.
- Add comments for complex logic.
- Ensure the notebook runs without errors.

### Testing

- Test your changes in the Jupyter notebook.
- Verify calculations are correct.
- Check UI interactions work as expected.

### Documentation

- Update README.md if you add new features.
- Add docstrings to new functions.
- Update examples if needed.
