The calculator holds 236 values in five categories. They are not all the same
physical quantity, which is why the running total is careful about what it
calls itself.

The table below is not written out here. It is read straight from
`notation/categories.csv`, the same file the calculator consults when it
decides how to head a total, so there is one description of a category in this
repository and not two that can drift apart.

{{csv: notation/categories.csv}}

The `Source` cell for the A-values is empty on purpose. Where those values came
from cannot be established from anything in this repository, and an invented
citation would be worse than an admitted gap. If you can identify the source,
that empty cell is where it goes.
