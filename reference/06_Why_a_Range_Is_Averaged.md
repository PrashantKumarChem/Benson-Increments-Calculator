Fifteen of the twenty-nine cyclohexane A-values are published as a range
rather than a single number — the hydroxyl A-value is given as 2.51-4.35
kJ/mol. The range is real: it reflects genuine disagreement between the
solvents and methods the measurements came from, not sloppiness.

A sum needs one number, so the calculator uses the midpoint. That is a fair
thing to add up and a misleading thing to print on its own, because 3.43
looks like a measurement and is not one. So the published range is shown
beside the value everywhere the value appears, and the running total reports
how far it could move if every averaged range in the sum were read at its
bounds instead of its middle.

Precision is handled the same way. A value is shown to the number of decimal
places its source actually claims: 195 of the 236 increments are written as
plain integers, so the calculator prints −42 rather than −42.00, which would
assert two decimals Cohen & Benson never published. An averaged range is the
one exception, since the midpoint of two two-decimal bounds can need a third
place — 1.05-1.76 averages to 1.405.
