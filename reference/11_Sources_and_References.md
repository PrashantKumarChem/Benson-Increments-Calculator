References are given in ACS style. Every one below has been checked against the
publisher's own record.

## The values in this calculator

- Cohen, N.; Benson, S. W. Estimation of Heats of Formation of Organic
  Compounds by Additivity Methods. *Chem. Rev.* **1993**, *93* (7), 2419–2438.
  [DOI: 10.1021/cr00023a005](https://doi.org/10.1021/cr00023a005)

  The source of the group increments and corrections, and the paper to cite for
  the method. This is the citation the calculator itself carries.

The cyclohexane A-values have no source recorded. See The Five Categories.

## The method

- Benson, S. W. *Thermochemical Kinetics: Methods for the Estimation of
  Thermochemical Data and Rate Parameters*, 2nd ed.; Wiley: New York, 1976.

  The book-length treatment, and where the group notation used throughout this
  calculator is set out.

- Ashcraft, R. W.; Green, W. H. Thermochemical Properties and Group Values for
  Nitrogen-Containing Molecules. *J. Phys. Chem. A* **2008**, *112* (38),
  9144–9152. [DOI: 10.1021/jp803759m](https://doi.org/10.1021/jp803759m)

  Group values for the nitrile, nitro, nitroso, nitrite, amine, imino and azo
  functions — the paper the nitrogen entries in the Notation table were checked
  against.

- Pappijn, C. A. R.; Van de Vijver, R.; Reyniers, M.-F.; Sabbe, M. K.;
  Marin, G. B.; Van Geem, K. M. Modeling the Thermochemistry of
  Nitrogen-Containing Compounds via Group Additivity. *Phys. Chem. Chem. Phys.*
  **2024**, *26* (27), 19021–19034.
  [DOI: 10.1039/D4CP00727A](https://doi.org/10.1039/D4CP00727A)

  A modern re-derivation of the nitrogen groups, useful for checking a value
  that looks wrong.

## Conformational analysis

- Eliel, E. L.; Wilen, S. H.; Mander, L. N. *Stereochemistry of Organic
  Compounds*; Wiley: New York, 1994. ISBN 0-471-01670-5.

  The standard reference for conformational analysis and for A-values.

## Editing this page

Every section of this page is a file in `reference/`. Prose is Markdown,
tables are CSV, the number at the front of the filename sets the order and the
rest of the filename becomes the heading. Adding a section means adding a
file — there is no code to change and no list to update.
