## The values in this calculator

- Cohen, N.; Benson, S. W. *Chem. Rev.* **1993**, *93*, 2419. — the source of
  the group increments and corrections, and the paper to cite for the method.
  This is the citation the calculator itself carries.

The cyclohexane A-values have no source recorded. See the note above.

## Background reading

- Benson, S. W. *Thermochemical Kinetics*, 2nd ed.; Wiley: New York, 1976. —
  the book-length treatment of the method, and where the group notation used
  throughout this calculator is set out.
- Eliel, E. L.; Wilen, S. H. *Stereochemistry of Organic Compounds*; Wiley:
  New York, 1994. — the standard reference for conformational analysis and
  for A-values.
- [NIST Chemistry WebBook](https://webbook.nist.gov/chemistry/) — measured
  enthalpies of formation, for checking an estimate against experiment.

## Editing this page

Every section of this page is a file in `reference/`. Prose is Markdown,
tables are CSV, the number at the front of the filename sets the order and the
rest of the filename becomes the heading. Adding a section means adding a
file — there is no code to change and no list to update.
