# Fall 2024 Teaching Artifacts (Year 1)

**Course:** CHEM-C 450 / CHEM-C 540 (Advanced Organic Chemistry), Indiana University Bloomington  
**Instructors:** Prashant Kumar, Dr. Nicola L. B. Pohl  
**Date:** September 24, 2024  

## Included Files

1. **`Chem540ClassNotes24Sept2024.pdf`**  
   Original lecture presentation slides. Introduces students to open-source software, Python installation via Anaconda Navigator, and using Jupyter Notebooks to solve the heat of formation of cyclopentadiene.

2. **`UpdatedBensonIncrementsCalculatorF24Chem540.ipynb`**  
   The interactive Jupyter Notebook developed for students using `pandas`, `ipywidgets`, and `IPython.display`. 

3. **`increment_correction_table_2024.csv`**  
   The initial 6-column tabular dataset of Benson group increments and corrections used by the 2024 notebook.

4. **`Bensen_increments_calculator_code_2024.pdf`**  
   Reference PDF printout of the 2024 Python script and widget callback logic.
